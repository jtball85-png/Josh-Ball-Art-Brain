# Minivan Dads — parked brand archive

Minivan Dads Inc. was this repo's original company: a POD apparel brand for
minivan-driving dads ("Old Guys Rule" playbook). On **2026-07-21 the CEO
pivoted the brain to run Josh Ball Art** and parked Minivan Dads — assets
preserved, no active work. Decision logged in `hq/decisions/log.md`
(2026-07-21); archived charter at `hq/charter/archive/minivan-dads-company.md`.

This folder collects the parked brand's product ideas and history so they
stay findable without cluttering the active project:

- `research/` — the garage research that powered the idea pipeline:
  ranked dad sayings / roadtrip one-liners, and the hats-and-patches
  market deep-dive (trucker caps, leather patches, typography and legal
  no-go patterns).
- `designs/` — the "Let's play the quiet game." tee: final SVG, print-ready
  300dpi files, flat preview, companion notes, and the Printful push spec
  that created it (the product still exists unpublished in the parked
  Minivan Dads Printful store, external_id `mvd-quiet-game-tee`, with an
  escalated-but-never-ruled $28 price).
- `specs/` — the original project handoff docs (project brief, phase
  roadmap, action-layer + boardroom specs, progress summary). These
  describe the brain's architecture as first built; the architecture
  itself now serves Josh Ball Art.

Still elsewhere, on purpose:
- `hq/` history (decisions, meetings, reports, escalations) is append-only
  and never rewritten — MVD-era records stay where they are.
- `garage/research/product-lineup-and-color-combos-2026-07-19.md` stays in
  the active garage: its product-economics findings (sticker margins,
  black/navy/heather color anchors, mug color combos) are brand-agnostic
  and actively cited by Josh Ball Art work.
- The MVD Printful store credentials live on in `.env` as
  `PRINTFUL_API_KEY_MVD` / `PRINTFUL_STORE_ID_MVD`.

Reviving any of this is a CEO decision first (see the pivot decision in
the log), then a directive change — not a file move.
